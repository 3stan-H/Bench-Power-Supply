This folder contains the project files for the Bench PSU through KiCad 10.0 as well as the BOM which represents the materials and components needed for this project with the MPN refering to the digikey part number. 

The BOM Also is missing a couple of things which include:

- Jumper Wires (MPN: 1954)
- 2x Potentiometers (MPN: PDB181-E420K-103B)

Keep in mind the schematic is missing some symbols which are present in "V2 Bench PSU KiCad 10.0 Files"
